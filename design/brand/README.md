# Congress Terminal – Emblem

The chamber seen from above: concentric rows of seats (solid arcs and dotted rows) open toward the
well, one seat lit in Capitol patina green (#2F6B5E). It echoes the seat charts used in the
briefing and reads, at small sizes, like a signal.

| File | Use |
|---|---|
| `emblem.svg` | Full mark, five rows, 48 px and up |
| `emblem-small.svg` | Three rows, below 48 px (favicon, tab) |
| `app-icon.svg` | Windows/PWA app icon on patina green |
| `emblem-dark.svg` | Dark mode |
| `make_emblem.py` | Generates all variants from exact geometry; edit here, not by hand |

Origin: concept explored with a Gamma image study (hemicycle of dotted and solid arcs), then
constructed as precise vector geometry. Never use the official seals of Congress, the House or the Senate.
